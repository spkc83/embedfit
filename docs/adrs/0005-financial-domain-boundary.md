# ADR 0005 — Financial-Risk Logic Does Not Enter Core Modeling

Status: Accepted

## Decision

The framework is domain-neutral.

Financial-services behavior belongs in examples, docs, and generic metric utilities.

## Rationale

The same representation-learning architecture applies to many image-classification tasks.

## Consequences

No hard-coded:

- fraud labels
- check fields
- RDI semantics
- bank-specific metadata
